PROBLEM

Rider safety requires proactive prevention against drunk driving, unstrapped helmet hazards, and rapid emergency notification during road accidents.

SOLUTION

Engineered a dual ESP32 IoT safety system utilizing ESP-NOW protocol. Integrates MQ3 alcohol sensor, MPU6050 crash sensor, and IR helmet detection to dispatch instant real-time Telegram alerts with live GPS coordinates upon accident detection.

KEY FEATURES

MY CONTRIBUTION

Embedded Systems Engineer & Firmware Developer — wrote ESP32 C++ firmware, calibrated sensor thresholds, and interfaced hardware components.
